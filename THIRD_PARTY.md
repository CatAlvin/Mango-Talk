# Acknowledgements

Mango Talk uses Vue, Pinia, Vue Router, Vite, Axios, FastAPI, SQLAlchemy, Uvicorn, Pillow, and their dependencies. Their package licenses remain applicable. Nginx, systemd, and MySQL provide the deployed runtime; their sources are not included here.

Application-specific work covers chat flows, the independent demo service, message reconciliation, attachment authorization, migration, and release tooling. Codex was used as a development tool during implementation and review.

Demo names, conversations, the checklist, and seaside illustration are fictional presentation material maintained with the project. Screenshots show that workspace rather than personal conversations.

# Mango Talk 1.0 验收记录

本次交付把正式聊天、公开演示和发布流程作为同一个版本维护。

## 修改

- 登录页加入注册和演示入口。演示共用正式 ChatView，通过独立本地数据服务运行；支持发送、引用、撤回、附件、历史、创建会话、刷新保存和重置。真实凭据、缓存、上传任务与连接均隔离。
- 消息使用唯一发送编号，HTTP 与 WebSocket 共用校验和去重服务。补齐最新窗口、双向游标、引用定位、重连新增消息与已加载消息撤回同步。
- 上传登记所有权，发送只接收上传编号；下载重新验证会话权限，链接十分钟失效。拒绝 HTML、SVG、损坏图片和空文件，撤回后隐藏正文与附件。
- 密码使用 scrypt，旧 bcrypt 验证后升级；登录命名空间使用共享唯一约束，退出撤销令牌。生产配置拒绝空密钥，现有连接重新验证账号状态和有效期。
- 加入会话摘要、未读和已读游标；批量加载发送者与引用。弹窗支持短屏滚动和焦点管理，图片预留尺寸，界面移除版本阶段和开发说明。
- 更新前端依赖和锁文件，加入前后端 CI、可重复迁移、提交绑定发布、数据库快照及应用恢复。生产进程使用专用用户，Nginx 加入认证限流和安全响应头。

## 发布

正式发布使用 `scripts/deploy.ps1`，先推送 GitHub `main`，再构建同一提交、备份 MySQL、运行迁移、切换独立版本并核对 HTTPS 健康与 `/release.json`。恢复流程见 [部署文档](../../deployment.md)。

本次仍使用单个 Uvicorn worker 和本地附件存储。后续增加多实例部署时，需同时引入共享消息分发与共享附件存储。
